# OctoPDF design reference

This folder preserves the original Google AI Studio reference project supplied for the OctoPDF redesign.

- `OctoPDF-AI-Studio-reference.zip` is a visual and interaction reference only.
- It is a React/Vite web prototype, not the Android application source.
- Do not copy its sample PDF data or simulated file operations into the Android app.
- Reimplement selected design patterns natively in Kotlin and Jetpack Compose, backed by the real PDF document model and file APIs.

The reference is retained for design comparison and feature planning; it is not included in the Android build.
